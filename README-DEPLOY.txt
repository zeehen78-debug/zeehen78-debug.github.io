DEPLOY TO YOUR EXISTING GITHUB PAGES REPOSITORY
1. Download and unzip this package.
2. Open https://github.com/zeehen78-debug/momentum-store
3. Back up the existing files first.
4. Upload/replace these files at the repository root. Keep any required existing files that are not included here only if they do not conflict.
5. In Settings > Pages, confirm the publishing source and branch (usually main / root).
6. Wait for the deployment to finish, then open https://zeehen78-debug.github.io/momentum-store/ and hard-refresh (Ctrl+F5).
